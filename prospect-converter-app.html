Contacts Views

By discovering how agents use the platform we restructured the contacts page. So there were added views lists for particular use cases, like “Pipeline Stage”. Which allows to analyse leads statistics in the context of all contacts which are in the pipeline.

Importing Records

While working on this flow, we added “Sample Data” to improve user awareness. We also introduced an additional feature called “Mapping Templates,” which helps reduce the time spent on repeating similar tasks.
