Onboarding

A structured onboarding flow where the user first selects their preferred sports and then moves through a proficiency level stepper with clear progress indicators showing how many steps remain. It’s important not to ask for registration too early, only when it becomes necessary.

User retention↑ ~50%
Onboarding completion↑ ~20%

Final steps

Completing details before starting interacting with other users. Plus getting familiar with the “community rules”.

Getting connected

Main goal is to let people interact, which is supported by suggesting people “near by”, with similar interests and possible phone contacts.

Next station – events / rounds.

Chatting

Since main purpose is “connecting”, chat was a “must have”. Considered basic messaging with notifications integrated, so user is informed about important changes in event details.
