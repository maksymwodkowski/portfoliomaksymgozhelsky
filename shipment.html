Shipping Platform - Shipment

Shipping Experience for Small Businesses

A web platform built to help small businesses and individual shippers manage deliveries, compare carrier rates, print labels, and track packages. The project focused on creating a simple, self‑service experience that supports quick actions and clear feedback.

Challenge 2: Key flow – batch shipment

Competitor research

By deploying this activity, we identified a user need that is not addressed in most of competitor experiences. Separate pricing selection for shipments within a batch. Since the business goal was to make the platform both easy to use and flexible, we decided to prioritize this flow.

Competitor 1: ShipStation

Competitor 2: OrderCup

User flow documentation

To communicate this flow, document it, and ensure we didn't miss any interactions, I designed a user flow diagram.

Ideas Validation – Vibe Coding

By using a Lovable, we were able to ideate and validate. After a few iterations, we considered key stakeholders feedback, which allowed us to come up with the best solution.

Final batch shipment design

Flow allows user process a batch, which is a list of items in one shipments entity.

Result

After testing session we found out that the best option is allow users to pre-select a “default” service for all shipments on the pre step, and change specific ones on the “Review” step.

Create Label

Generates shipping labels for shipments or batches, covering carrier, weight, and shipping options.

Integrations

Connects marketplaces, ERPs, and CRMs, automatically importing orders and syncing shipment data.
