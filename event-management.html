Event Requests List

Comes as a “Intake & Sourcing” module. Main page for the events managers. Here they are able to set priority, change status, view existing details and assign it to a particular owner.

Event

Allows user to fill in a full info, plus add agenda and see a summary in real time.

Key Challenge

The task was to keep all the details on one page, in addition include agenda set up and navigation between sub events. Here the “Vibe Coding” method saved us a lot of time on the validation. So we were able to have testing sessions with actual users of this product. And based on the feedback we adjusted a best fit option.

Venues & Contacts

Basic contacts lists. With full interactions behind them, like adding contact and editing it as well as deleting confirmation.

Settings

Here event managers were able to set up rules for workflow automation. Like adding “Contract Terms” and allowing it to be used as a template for proposals mails.
